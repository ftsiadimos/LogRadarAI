Configuration Guide

Setting up Telegram Notifications

  1. Open Telegram and search for @BotFather
  2. Send /newbot and follow the instructions to create a bot
  3. Copy the bot token and paste it above
  4. To get your Chat ID:
    • Send a message to your bot
    • Visit https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates
    • Find the chat.id in the response
  5. Click "Test Connection" to verify

Setting up Ollama

  1. Install Ollama from ollama.ai
  2. Run: ollama pull llama3.2
  3. Start Ollama: ollama serve
  4. Verify it's running at http://localhost:11434

Rsyslog Configuration

Add this to your rsyslog configuration to send logs to LogAI Monitor:

# /etc/rsyslog.d/99-logaimonitor.conf
*.* @logaimonitor-host:5514  # UDP
# OR
*.* @@logaimonitor-host:5515 # TCP
