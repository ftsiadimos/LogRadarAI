AI-Powered Log Monitoring & Analysis

LogRadarAI is an intelligent log monitoring and analysis platform that combines traditional syslog collection with cutting-edge AI capabilities. It provides real-time log aggregation, smart filtering, and AI-powered analysis to help system administrators identify and resolve issues faster.

Key Features

  • Real-time syslog collection (UDP/TCP)
  • Docker container log monitoring
  • AI-powered log analysis with Ollama
  • Custom filters and alert rules
  • Telegram notifications
  • AI Chat Assistant for log analysis
  • Duplicate log detection
  • Hostname/FQDN tracking

Technology Stack

  • Python / Flask
  • Redis
  • Ollama (Local AI)
  • Docker
  • Socket.IO (Real-time)
  • Telegram Bot API
